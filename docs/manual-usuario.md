# Manual de usuario

## Registro

1. Abrir la aplicacion web.
2. Ingresar a la opcion de crear cuenta.
3. Completar nombre, correo electronico, contrasena y confirmacion.
4. Presionar "Registrarme".
5. Si Supabase requiere confirmacion, revisar el correo electronico y completar la activacion.

## Inicio de sesion con email

1. Abrir la pantalla de login.
2. Ingresar correo electronico y contrasena.
3. Presionar "Ingresar".
4. Si las credenciales son correctas, el sistema redirige al chat.

## Inicio de sesion con Google

1. En login o registro, presionar "Continuar con Google".
2. Seleccionar la cuenta de Google.
3. Autorizar el acceso.
4. El sistema redirige al chat cuando Supabase confirma la sesion.

## Crear nueva conversacion

1. En el chat, abrir la barra lateral de conversaciones.
2. Presionar "Nueva conversacion".
3. El area principal queda lista para iniciar una consulta.

## Seleccionar tema

1. En el encabezado del chat, abrir el selector "Tema".
2. Elegir un tema del programa de AED I.
3. Escribir la consulta y enviarla.

## Enviar consultas

1. Escribir la pregunta en la barra inferior.
2. Presionar el boton de envio.
3. Esperar la respuesta del tutor.
4. Revisar la explicacion y, si es necesario, pedir aclaraciones.

## Pedir ejercicios

El estudiante puede solicitar ejercicios con frases como:

- "Generame un ejercicio basico de colas".
- "Dame un ejercicio de busqueda binaria".
- "Quiero practicar recursividad".

El tutor puede entregar enunciado, pistas progresivas y explicaciones. Si el estudiante pide la solucion completa, el tutor puede mostrarla de forma guiada.

## Recuperar conversaciones

1. Abrir el sidebar de conversaciones.
2. Seleccionar una sesion anterior.
3. El sistema carga los mensajes asociados.
4. Se puede continuar la conversacion desde el historial.

## Cerrar sesion

1. Abrir el sidebar.
2. Presionar "Salir".
3. El sistema cierra la sesion y vuelve al acceso inicial.

## Uso desde celular

En celular, el sidebar se abre mediante el boton hamburguesa. El chat ocupa todo el ancho disponible, el input permanece abajo y el selector de tema se acomoda en una disposicion compacta. Se recomienda escribir consultas breves y revisar las respuestas con desplazamiento vertical dentro del area de mensajes.
