# Encuesta de experiencia de usuario del STI

Instrumento para evaluar la version congelada del Sistema Tutor Inteligente de Algoritmos y Estructuras de Datos I (AED I). No contiene resultados ni datos de participantes.

## Consentimiento informado

La participacion en esta evaluacion es voluntaria. Las respuestas seran utilizadas exclusivamente con fines academicos en el marco del Trabajo Final de Grado y seran analizadas de forma anonima y agregada. No se solicitaran datos que permitan identificar directamente al participante. Al continuar, declara haber comprendido esta informacion y aceptar participar voluntariamente.

[ ] Acepto participar voluntariamente.

Si no acepta, no debe continuar con el cuestionario. El consentimiento funciona como condicion de participacion y no integra las 12 preguntas numeradas del instrumento.

## Anonimizacion y tratamiento de respuestas

- No se solicita nombre, correo electronico ni matricula.
- No se recopilan identificadores directos de la persona participante.
- Los resultados se analizaran de forma anonima y agregada.
- Si posteriormente se implementa en Google Forms, debe desactivarse la recopilacion automatica de direcciones de correo electronico.

## Bloque A — Perfil de uso

1. ¿Cual es su relacion actual con Algoritmos y Estructuras de Datos I? (cursando / asignatura aprobada / docente / otra). **Respuesta unica.**
2. ¿Ha utilizado anteriormente asistentes de inteligencia artificial para estudiar? (si / no / ocasionalmente). **Respuesta unica.**

## Bloque B — Valoracion de la experiencia

Para las preguntas 3 a 10, utilice la siguiente escala:

- 1 = Totalmente en desacuerdo
- 2 = En desacuerdo
- 3 = Ni de acuerdo ni en desacuerdo
- 4 = De acuerdo
- 5 = Totalmente de acuerdo

3. El sistema fue facil de usar.
4. La navegacion entre conversaciones fue intuitiva.
5. El historial me permitio retomar consultas anteriores facilmente.
6. Las respuestas del tutor fueron claras.
7. La presentacion de las respuestas fue legible y ordenada.
8. Las respuestas fueron pertinentes para mis consultas sobre AED I.
9. El STI me resulto util para comprender contenidos de AED I.
10. El tiempo de respuesta fue aceptable para estudiar.
